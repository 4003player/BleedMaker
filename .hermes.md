# BleedMaker

**Bleed extension tool** — extends the edges of artwork images to create bleed for printing. Targeted at JPG/PNG/TIFF production files.

**Live:** https://4003player.github.io/BleedMaker/  
**Repo:** https://github.com/4003player/BleedMaker.git  
**Stack:** Single-file `index.html` (~720 lines), no build step, GH Pages hosted.

## Architecture

- Pure JavaScript — no PDF library needed (works on raster images)
- Image parsing: custom JPEG, PNG, TIFF header parsers for dimension/DPI detection

## What It Does

1. User uploads an image (JPG/PNG/TIFF)
2. Detects dimensions and DPI from file headers
3. User specifies desired bleed amount
4. Generates extended image with bleed created by mirroring/reflecting edge content

## Key Functions

- `parseJpegDims()` / `parsePngInfo()` / `parseTiffInfo()` — native header parsing
- `detectDpi()` — extracts DPI from image metadata
- `numVal()` — Safari-safe numeric input parsing
- `parseTiffFromIfd()` — TIFF IFD parsing (IFD can be at EOF; requires two-pass read)

## Bleed Generation Methods

- **Fast method:** ImageMagick-style mirror distort (canvas reflect)
- **HQ method:** "Onion peel" approach (planned: PhotoCraft WASM — see `~/photocraft-wasm-plan.md`)
- Spot healing bleed: start ~2× bleed distance inside the edge, work one side at a time

## Critical Rules

1. **TIFF IFD at EOF** — TIFF files can have their IFD (Image File Directory) at the end of the file; the parser needs a two-pass read
2. **`numVal()` helper** — Safari compatibility
3. **Fly `/bleed` on gs-thumbnail-server** — related server-side generation path
